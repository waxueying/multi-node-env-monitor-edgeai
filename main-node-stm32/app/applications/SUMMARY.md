# STM32F407ZGT6 项目完成总结

## 📋 项目概览

为STM32F407ZGT6微控制器创建了完整的应用层框架，实现了三个独立的功能模块，通过多线程并发处理实现CAN数据接收、云端上传和本地备份。

---

## ✅ 完成的工作

### 1. CAN接收模块 ✓
**文件：** `can_receiver.c` / `can_receiver.h`

**功能：**
- 支持两个CAN ID的数据接收（CAN_ID_1=0x001, CAN_ID_2=0x002）
- 使用消息队列（32条容量）缓存CAN数据
- 独立接收线程在后台持续监听
- 时间戳记录功能

**关键函数：**
```c
can_receiver_init()        // 初始化
can_receiver_start()       // 启动线程
can_receiver_get_data()    // 获取数据
can_receiver_get_count()   // 获取队列长度
```

**线程信息：** 
- 线程名：`can_rx`
- 优先级：15（较高）
- 栈大小：1024字节

---

### 2. WiFi/MQTT模块 ✓
**文件：** `mqtt_client.c` / `mqtt_client.h`

**功能：**
- 通过AT指令驱动ESP8266模块
- 自动连接WiFi网络
- MQTT协议支持，数据上传到云端
- JSON格式的数据封装
- WiFi连接状态监控
- 自动断线重连机制

**关键函数：**
```c
mqtt_client_init()           // 初始化配置
mqtt_client_start()          // 启动服务
mqtt_client_publish_can_data()  // 发布CAN数据
mqtt_client_is_wifi_connected() // 检查WiFi连接
mqtt_client_get_status()     // 获取连接状态
```

**线程信息：**
- MQTT处理线程：`mqtt_thread`，优先级12，栈大小2048字节
- WiFi监控线程：`wifi_monitor`，优先级13，栈大小1024字节

**重要特性：**
- 5秒周期WiFi连接检查
- 网络断开时自动触发SD卡备份
- 指数退避重连算法（最长等待30秒）
- 支持可配置的MQTT broker和发布主题

---

### 3. SD卡存储模块 ✓
**文件：** `sd_storage.c` / `sd_storage.h`

**功能：**
- 自动挂载SD卡（FAT32格式）
- 缓冲区管理机制（256条记录容量）
- 数据定期刷新到SD卡（10秒周期）
- WiFi断开时自动保存CAN数据
- 支持批量读写操作

**关键函数：**
```c
sd_storage_init()            // 初始化
sd_storage_start()           // 启动线程
sd_storage_save_record()     // 保存单条记录
sd_storage_save_batch()      // 批量保存
sd_storage_read_records()    // 读取记录
sd_storage_is_mounted()      // 检查挂载状态
```

**存储位置：**
- 数据文件：`/sd/can_data.bin`（二进制格式）
- 日志文件：`/sd/system.log`（预留）

**线程信息：**
- 线程名：`sd_storage`
- 优先级：14
- 栈大小：1024字节

---

### 4. 主程序集成 ✓
**文件：** `main.c`

**功能：**
- 初始化并启动所有三个模块
- 创建数据转发线程处理业务逻辑
- 智能路由：
  - WiFi连接 → MQTT发送
  - WiFi断开 → SD卡备份
- 周期性状态输出

**数据转发线程：**
- 线程名：`data_forward`
- 优先级：11（低于其他处理线程）
- 栈大小：1024字节

## 🔧 快速配置

### 步骤1：配置WiFi和MQTT

编辑 `main.c` 的 `mqtt_config` 结构体：

```c
static mqtt_config_t mqtt_config = {
    .wifi_ssid = "YOUR_SSID",           // 修改为你的WiFi名称
    .wifi_password = "YOUR_PASSWORD",   // 修改为你的WiFi密码
    .mqtt_broker = "your.broker.com",   // 修改为MQTT服务器
    .mqtt_port = 1883,
    .mqtt_client_id = "stm32_device",
    .mqtt_publish_topic = "device/can/data"
};
```

### 步骤2：配置CAN ID

编辑 `can_receiver.h`：

```c
#define CAN_ID_1 0x001   // 修改为实际的CAN ID
#define CAN_ID_2 0x002   // 修改为实际的CAN ID
```

### 步骤3：验证UART配置

检查 `mqtt_client.c` 中的UART设备名称（默认uart2）。

## 🔐 关键设计特点

### 1. 多线程并发处理
- 各模块独立运行，互不阻塞
- 线程优先级合理分配
- 使用消息队列和信号量进行同步

### 2. 自适应网络管理
- WiFi连接状态实时监测
- 自动断线重连（3次重试）
- 指数退避算法防止频繁重连

### 3. 数据可靠性保证
- 双重缓存机制（CAN队列 + SD缓冲）
- WiFi断开时自动本地备份
- 缓冲满时告警处理

### 4. 易于扩展
- 模块化设计，各模块独立
- 接口清晰，易于调用
- 配置集中在一个地方
